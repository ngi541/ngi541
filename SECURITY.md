# 10. `SECURITY.md`

На початку не треба вигадувати security email, якого немає.

```markdown
# Security Policy

## Project status

NGI541 is currently under early development and has not reached a stable
release.

The project must not currently be treated as production-ready cryptographic
software.

## Reporting a vulnerability

Do not disclose suspected security vulnerabilities through a public GitHub
issue.

While the repository remains private, security findings should be communicated
directly to the repository owner.

A dedicated vulnerability-reporting mechanism will be published before the
first public release.

## Cryptographic assurance

NGI541 has not been independently audited.

NGI541 has not been validated under FIPS 140-3.

No claim of FIPS validation or certification should be inferred from project
architecture, documentation, algorithm support, or test results.
