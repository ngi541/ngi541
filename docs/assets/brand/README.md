# NGI541 Brand Assets

Canonical project assets for the NGI541 open-source project.

- `logo-light.svg` — primary horizontal logo for light backgrounds.
- `logo-dark.svg` — primary horizontal logo for dark backgrounds.
- `mark-light.svg` — compact vertical mark for light backgrounds.
- `mark-dark.svg` — compact vertical mark for dark backgrounds.
- `mark-avatar.svg` — compact mark on a fixed white square for organization/profile avatars.

All SVGs use vector paths and geometric strokes only. They contain no embedded fonts,
raster images, scripts, or external resources.

Usage rules:
- Preserve aspect ratio.
- Do not alter the spacing between `NGI` and `541`.
- Do not recolor individual elements independently.
- Keep adequate clear space around the logo/mark.
